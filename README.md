# EcoConnect Hub

Je voudrais qu'on travaille sur une plateforme de mise en relation. Quand je dis mise en relation, ce n'est pas comme si les deux personnes qu'on met en relation vont se contacter. Non, elles ne vont pas pouvoir se contacter directement. Il s'agit d'une plateforme de recyclage où il y aura les utilisateurs d'un côté qui vont pouvoir déclarer leurs déchets recyclables, et de l'autre côté, les entreprises qui vont pouvoir programmer leur tournée pour venir acheter ces déchets. Le problème, c'est que les clients ont leurs déchets chez eux à la maison, mais du fait de la distance, ne peuvent pas aller individuellement chez les entreprises. Les entreprises aussi ne peuvent pas aller chez chaque client individuellement. Donc il leur faut une solution pour pouvoir identifier les ménages ou les clients qui ont les déchets recyclables chez eux et en fonction de cela, ils vont programmer une journée où ils vont passer récolter chez tous les clients.

Quand on parle ici de matières recyclables, ce n'est pas seulement le plastique. Il s'agit aussi de ce qui est métallique : le cuivre, le fer, tout ce qui est métallique en fait partie.

La solution doit être mobile first. Dès les premiers trucs, on va installer le système de PWA pour qu'on puisse installer l'application web.
Direction visuelle choisie : Éco moderne (vert forêt et blanc, coins arrondis, ambiance confiance et propreté).
